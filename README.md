# Anush Bathla — Portfolio Website

A responsive, premium blue-and-white portfolio built with plain HTML, CSS, and JavaScript.

## Run locally
1. Extract the ZIP.
2. Open `index.html` in a browser.

For a local development server, open a terminal in this folder and run:
- `python -m http.server 5500`
- Visit `http://localhost:5500`

## Customize
- Update bio, projects, education, and links in `index.html`.
- Adjust colors and layout in `style.css`.
- Change the rotating hero phrases in `script.js`.

## Publish
You can deploy the folder using GitHub Pages, Netlify, or Vercel static hosting.

Note: project descriptions are presented as concepts/prototypes where appropriate; update each project's status and links as your work progresses.
